# Микросервисная архитектура: Services, Consumer и gRPC Server

Этот набор репозиториев демонстрирует реализацию микросервисной архитектуры. Система состоит из трёх основных компонентов: Бизнес-логики, потребителя сообщений и gRPC-сервера.

---

## Репозитории

- **Services**: https://github.com/RogovKonstantin/services
- **Consumer**: https://github.com/RogovKonstantin/consumer
- **gRPC Server**: https://github.com/RogovKonstantin/grpc-server

---

## Компоненты архитектуры

### 1. Services
* Реализует бизнес-логику и предоставляет gRPC-интерфейсы для взаимодействия с другими сервисами.
* Основные функции:
  * Обработка входящих gRPC-запросов.
  * Взаимодействие с базой данных для выполнения операций CRUD.
  * Отправка сообщений в очередь для асинхронной обработки.

### 2. Consumer
* Потребляет сообщения из очереди и выполняет соответствующие действия.
* Основные функции:
  * Подписка на очередь сообщений.
  * Обработка полученных сообщений.
  * Взаимодействие с другими сервисами при необходимости.

### 3. gRPC Server
* Обеспечивает точку входа для gRPC-запросов от внешних клиентов.
* Основные функции:
  * Приём и маршрутизация gRPC-запросов к соответствующим сервисам.
  * Управление соединениями и обеспечение безопасности.
